接入指引

四步接入，一次配置，永久有效

STEP 01

生成私人令牌

登录班蔚，进入「个人中心 → 品牌形象 → 私人令牌」，点击「生成新令牌」。明文只显示一次——生成后立刻复制，关掉就看不到了。
bash 
curl -s -X POST https://bluvarri.com/mcp-gateway/mcp \
  -H "Content-Type: application/json" \
  -H "Accept: application/json" \
  -H "Accept: text/event-stream" \
  -H "Authorization: Bearer 你的_令牌" \
  -d '{
    "jsonrpc": "2.0",
    "id": 100,
    "method": "tools/call",
    "params": {
      "name": "find_friends",
      "arguments": {}
    }
  }'
STEP 02

写入客户端配置

打开 AI 客户端的配置文件（支持 MCP 的客户端均可），在 mcpServers 字段追加以下内容：

json 
{
  "mcpServers": {
    "bv_mcp_connector": {
        "url": "https://bluvarri.com/mcp-gateway/mcp",
        "headers": {
            "Authorization": "Bearer 你的_令牌",
        },
    }
  }
}
STEP 03

重启并确认连接

完全退出并重启客户端。工具面板出现「bv_mcp_connector」且亮绿灯，即表示连接成功。若没出现，检查 Token 是否粘贴完整。

bash 
# 也可以通过 CLI 验证
mcp list
STEP 04

用自然语言开始工作

不用记参数，不用看文档。像对人说话一样描述你的需求，AI 自己判断调哪个工具、传什么参数、返回什么结果。

AI：收到，正在搜索…
    [调用 search_gigs → q="插画" budgetMax=300 sbu="day"]

    共找到 6 个匹配服务，以下是评分最高的 3 个：
    ① 达意设计  · 商业插画定制  ¥280/天  ⭐ 4.9 (37 评价)
    ② 小鹿插画  · 品牌 IP 设计  ¥250/天  ⭐ 4.8 (21 评价)
    ③ 云端画室  · 头像 / 表情包  ¥180/天  ⭐ 4.7 (58 评价)
